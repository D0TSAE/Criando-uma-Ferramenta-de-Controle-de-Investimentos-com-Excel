# Criando-uma-Ferramenta-de-Controle-de-Investimentos-com-Excel

## Sobre a aula

Criação de ferramenta de controle de investimentos utilizando planilhas eletrônicas.

A ferramenta foi criada para facilitar a organização e o acompanhamento de uma carteira de investimentos FIs, permitindo visualizar informações importantes de forma simples e organizada.

## Funcionalidades

- Cadastro e organização dos investimentos;
- Controle dos valores investidos;
- Cálculo de rentabilidade;
- Acompanhamento do valor atual da carteira;
- Organização das informações dos ativos;
- Utilização de fórmulas para automatizar cálculos;
- Apresentação das informações de forma visual e organizada.

## Estrutura do projeto

O projeto possui uma planilha principal para o controle dos investimentos e uma estrutura de dados utilizada para armazenar informações dos ativos.

### Controle de investimentos

Área destinada ao acompanhamento da carteira, incluindo valores investidos, rentabilidade e resultados.

### Base de dados

Área destinada à organização das informações utilizadas pela ferramenta, como ativo, perfil do investidor, tipo de investimento e porcentagem.

## Tecnologias utilizadas

- Microsoft Excel / LibreOffice Calc
- Fórmulas e funções de planilha
- Gráficos e recursos de formatação

## Objetivo

Desenvolver uma ferramenta simples e funcional para auxiliar no controle de uma carteira de investimentos, aplicando conhecimentos de organização de dados, cálculos, automação e visualização de informações.
